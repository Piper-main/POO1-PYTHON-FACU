GUÍA DIARIA — PYTHON + VS CODE + GIT + GITHUB

OBJETIVO:
Trabajar en Linux y mantener los programas guardados tanto en la PC como en GitHub.

==================================================

1. ENCENDER LA PC Y PREPARAR EL PROYECTO
   ==================================================

2. Abrir una terminal.

3. Ir a la carpeta del proyecto:

cd "ruta/de/tu/proyecto"

En mi caso:

cd "$HOME/Escritorio/POO 1/python"

3. Traer posibles cambios de GitHub:

git pull

IMPORTANTE:
No hacer "git init".
El repositorio ya está creado.

==================================================
2. ABRIR EL PROYECTO EN VS CODE
===============================

4. Desde la carpeta del proyecto ejecutar:

code .

5. VS Code se abrirá directamente en el proyecto.

6. Trabajar normalmente.

==================================================
3. CADA VEZ QUE CREO O MODIFICO UN PROGRAMA
===========================================

7. Crear el archivo .py desde VS Code.

Ejemplo:

Practicas/mi_programa.py

8. Guardar:

Ctrl + S

IMPORTANTE:
Ctrl + S solamente guarda el archivo en la PC.
Todavía NO está guardado en GitHub.

==================================================
4. GUARDAR EL PROGRAMA EN GIT
=============================

Cuando termine una parte importante del trabajo:

9. Abrir la terminal de VS Code o una terminal de Linux.

10. Comprobar los cambios:

git status

11. Agregar los cambios:

git add .

12. Crear un commit:

git commit -m "Agrego nuevo programa de Python"

13. Subirlo a GitHub:

git push

==================================================
5. PARA PROTEGER EL TRABAJO SI HAY UN CORTE DE LUZ
==================================================

NO alcanza solamente con Ctrl + S.

Usar esta rutina cada vez que termine un programa:

Ctrl + S

git add .

git commit -m "Agrego ejercicio de Python"

git push

Después de "git push", el trabajo queda:

PC → Git → GitHub

==================================================
6. SI HAGO MUCHOS PROGRAMAS DURANTE EL DÍA
==========================================

No es necesario hacer un commit después de cada Ctrl + S.

Se recomienda hacer un commit cuando:

* Terminé un programa.
* Terminé una parte importante.
* Corregí un error importante.
* Terminé una sesión de estudio.
* Antes de dejar la PC.
* Antes de apagar la PC.

Ejemplo:

Programa 1 terminado:

Ctrl + S

git add .
git commit -m "Agrego ejercicio de condicionales"
git push

Programa 2 terminado:

Ctrl + S

git add .
git commit -m "Agrego ejercicio de bucles"
git push

==================================================
7. AL TERMINAR DE ESTUDIAR O TRABAJAR
=====================================

ANTES DE APAGAR LA PC:

1. Guardar todos los archivos:

Ctrl + S

2. Comprobar:

git status

3. Si hay cambios:

git add .

4. Crear el último commit:

git commit -m "Finalizo sesión de estudio"

5. Subir a GitHub:

git push

6. Comprobar:

git status

Debe decir:

"nada para hacer commit, el árbol de trabajo está limpio"

Ahora puedo apagar la PC.

==================================================
8. AL DÍA SIGUIENTE
===================

Encender la PC.

Abrir terminal.

Ir al proyecto:

cd "$HOME/Escritorio/POO 1/python"

Traer cambios:

git pull

Abrir VS Code:

code .

Trabajar normalmente.

==================================================
9. LOS 5 COMANDOS MÁS IMPORTANTES
=================================

git status
→ ¿Qué cambió?

git add .
→ Preparar los cambios.

git commit -m "Descripción"
→ Crear una nueva versión.

git push
→ Subir la versión a GitHub.

git pull
→ Traer cambios desde GitHub.

==================================================
REGLA PARA RECORDAR
===================

Ctrl + S
→ Guarda en la PC.

git commit
→ Guarda una versión en Git.

git push
→ Guarda esa versión en GitHub.

==================================================
RUTINA COMPLETA
===============

AL EMPEZAR:

cd "$HOME/Escritorio/POO 1/python"
git pull
code .

DURANTE EL TRABAJO:

Ctrl + S

AL TERMINAR UN PROGRAMA:

Ctrl + S
git status
git add .
git commit -m "Agrego programa nuevo"
git push

AL TERMINAR EL DÍA:

Ctrl + S
git status
git add .
git commit -m "Finalizo sesión de estudio"
git push
git status

IMPORTANTE:

git init → solamente la primera vez.

git clone → solamente cuando preparo una PC nueva.

git pull → para traer cambios de GitHub.

git push → para enviar mis cambios a GitHub.
