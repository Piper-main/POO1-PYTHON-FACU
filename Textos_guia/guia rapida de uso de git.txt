GUÍA RÁPIDA — GIT + GITHUB + PYTHON EN LINUX
OBJETIVO:
Conectar una carpeta de programas Python de la PC con un repositorio de GitHub.
==================================================
PARTE 1 — PRIMERA CONFIGURACIÓN DE LA PC
    1. Comprobar que Git está instalado:
git --version
    2. Configurar nombre:
git config --global user.name "Piper"
    3. Configurar correo de GitHub:
git config --global user.email "TU_CORREO"
    4. Comprobar:
git config --global user.name
git config --global user.email
==================================================
PARTE 2 — PREPARAR LA CARPETA
    5. Entrar a la carpeta donde están los programas Python:
cd "RUTA-DE-TU-CARPETA"
Ejemplo:
cd ~/Escritorio/POO\ 1/python
    6. Comprobar que estamos en la carpeta correcta:
pwd
ls
==================================================
PARTE 3 — CREAR EL REPOSITORIO GIT LOCAL
    7. Inicializar Git:
git init
    8. Cambiar la rama a main:
git branch -m main
==================================================
PARTE 4 — CREAR .gitignore
    9. Crear el archivo:
nano .gitignore
    10. Escribir:
pycache/
*.py[cod]
.venv/
venv/
env/
.env
.vscode/
*.save
    11. Guardar en nano:
Ctrl + O
Enter
Ctrl + X
==================================================
PARTE 5 — PRIMER COMMIT
    12. Ver qué archivos encontró Git:
git status
    13. Agregar los archivos:
git add .
    14. Comprobar:
git status
    15. Crear el primer commit:
git commit -m "Primer commit - trabajos POO 1"
    16. Comprobar:
git status
Debe aparecer:
nada para hacer commit, el árbol de trabajo está limpio
==================================================
PARTE 6 — CONECTAR CON GITHUB
    17. Crear primero el repositorio en GitHub.
IMPORTANTE:
El repositorio de GitHub debe existir antes de ejecutar el siguiente comando.
    18. Conectar la carpeta local con GitHub:
git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
Ejemplo:
git remote add origin https://github.com/Piper-main/POO1-PYTHON-FACU.git
    19. Comprobar la conexión:
git remote -v
Debe aparecer origin para fetch y push.
==================================================
PARTE 7 — PRIMER PUSH
    20. Subir el proyecto:
git push -u origin main
    21. Si pide:
Username for 'https://github.com':
Escribir el usuario de GitHub.
    22. Si pide:
Password for 'https://USUARIO@github.com':
NO usar la contraseña normal de GitHub.
Usar un Personal Access Token (PAT) de GitHub.
IMPORTANTE:
El token funciona como una contraseña.
NO compartirlo con nadie.
==================================================
PARTE 8 — A PARTIR DE AHORA
Cada vez que cree o modifique un programa:
    1. Guardar el archivo.
    2. Ver cambios:
git status
    3. Preparar cambios:
git add .
    4. Crear commit:
git commit -m "Descripción del cambio"
Ejemplo:
git commit -m "Agrego ejercicio de listas"
    5. Subir a GitHub:
git push
==================================================
PARA VER EL HISTORIAL
git log --oneline
==================================================
SI TRABAJO DESDE OTRA PC
NO hacer git init si voy a descargar un repositorio que ya existe.
    1. Clonar el repositorio:
git clone https://github.com/TU-USUARIO/TU-REPOSITORIO.git
Ejemplo:
git clone https://github.com/Piper-main/POO1-PYTHON-FACU.git
    2. Entrar:
cd POO1-PYTHON-FACU
    3. Trabajar normalmente.
    4. Para subir cambios:
git add .
git commit -m "Descripción del cambio"
git push
==================================================
SI QUIERO TRAER CAMBIOS DE OTRA PC
Antes de empezar a trabajar:
git pull
==================================================
RESUMEN
PRIMERA VEZ:
git init
git branch -m main
git add .
git commit -m "Primer commit"
git remote add origin URL_DEL_REPOSITORIO
git push -u origin main
USO NORMAL:
git status
git add .
git commit -m "Descripción"
git push
SI CAMBIO DE PC:
git clone URL_DEL_REPOSITORIO
Y después:
git pull
git add .
git commit -m "Descripción"
git push
REGLA IMPORTANTE:
Git = guarda versiones en la PC.
GitHub = guarda el repositorio remoto en Internet.
git push = PC → GitHub
git pull = GitHub → PC
